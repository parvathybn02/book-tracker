# PageTurn – Book Tracker

PageTurn is a simple, responsive web application that helps readers organize their personal book collection, track reading progress and record their thoughts about books.

## Features

- **Add Books:** Save a book's title, author, genre and optional cover image.
- **Reading Status:** Organize books into To Read, Reading and Finished categories.
- **Search Books:** Quickly find books by title or author.
- **Reading Statistics:** View the total number of books and track reading progress.
- **Monthly Reading Goal:** Set a reading target and monitor progress toward it.
- **Ratings and Notes:** Rate finished books and add personal notes.
- **Reading Constellation:** Explore visual connections between books based on shared genres or themes.
- **Dark Mode:** Switch between light and dark themes.
- **Delete Books:** Remove books from your collection when needed.
- **Persistent Storage:** Book details and preferences are saved in the browser using localStorage.
- **Responsive Design:** Designed to work on desktop, tablet and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- SVG for interactive visualizations

## Project Structure

- `index.html` – Application structure and interface
- `style.css` – Styling, layouts and responsive design
- `script.js` – Application functionality and data management
- `README.md` – Project documentation
- `PROMPTS.md` – AI prompts used during development

## Data Storage

PageTurn uses browser localStorage to save books, reading goals and theme preferences. Data remains available after refreshing the page in the same browser and website origin.

**Note:** Data is stored locally in the browser and is not synchronized across different browsers or devices.

## Project Objective

The objective of PageTurn is to provide a convenient and user-friendly way to manage a personal reading list, monitor reading habits and make the reading experience more engaging through personalization and visual features.
